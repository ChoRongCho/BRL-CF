# 설문 문항 통합 정리 — Fluency · STS · TOAST

세 논문의 설문 문항을 서지정보, 설문 구성, 영어 원문, 응답·채점 순서로 정리했다. Fluency는 논문의 실제 실험에서 사용한 8문항, STS와 TOAST는 최종 제안한 15문항과 9문항을 수록한다. 각 설문은 독립적으로 실시·채점한다.

인용수는 기존 문서에 기록된 **2026-09-13 조회값**을 옮겼으며 이번 정리에서 재조회하지 않았다.

## R 표기와 역채점의 의미

**R은 reverse-scored(역채점) 문항이라는 뜻이다.** 부정적으로 표현된 문항은 동의할수록 평가가 나빠지므로, 점수를 뒤집어 다른 문항과 같은 방향으로 맞춘 뒤 합계나 평균을 계산한다. 응답자는 문장에 대한 자신의 동의 정도를 그대로 선택하고, **분석하는 사람이 채점할 때 변환**한다.

예를 들어 STS의 “The statistical model is incompetent.”는 “이 통계 모델은 무능하다”는 뜻이다. 이 문장에 강하게 동의한 5점을 그대로 더하면 무능하다는 평가가 성능 점수를 높이게 된다. 따라서 5점을 1점으로 바꾼다.

| 응답 척도 | 역채점 공식 | 점수 변환 |
| --- | --- | --- |
| 1–5점 | 역채점 값 = 6 − 원래 응답 | 1↔5, 2↔4, 3은 그대로 |
| 1–7점 | 역채점 값 = 8 − 원래 응답 | 1↔7, 2↔6, 3↔5, 4는 그대로 |

**R은 문항 삭제 표시가 아니고, 영어 문장을 반대로 고쳐 쓰라는 뜻도 아니다.** 원래 문장을 그대로 제시하고 점수만 변환한다. 이미 역채점한 데이터에는 다시 적용하지 않는다.

**논문:** Evaluating Fluency in Human–Robot Collaboration  

### 설문 구성 및 응답

사람과 로봇의 협업 흐름과 로봇의 기여도·특성 등을 평가한다. 온라인 실험에서 참가자는 협업 시뮬레이션 영상을 보고 다음 8문항에 응답했다.

- **문항 위치:** Table I, 논문 p. 215 / PDF 7쪽.
- **응답:** 7-point Likert scale — “strongly disagree”부터 “strongly agree”.
- **평가 관점:** 영상을 본 관찰자.
- **표기:** S1–S8은 정리를 위한 번호이며, 문구와 R 표기는 원문을 유지했다.

### 영어 원문 — 실험 사용 8문항 전체

| ID | English indicator — verbatim | Table I의 표기 |
| --- | --- | --- |
| S1 | The human-robot team worked fluently together | |
| S2 | The human was the most important member of the team | |
| S3 | The robot was intelligent (R) | R |
| S4 | The robot was trustworthy | |
| S5 | The robot was uncooperative (R) | R |
| S6 | The robot contributed to the fluency of the collaboration | |
| S7 | The robot was committed to the success of the team | |
| S8 | The robot had an important contribution to the success of the team | |

### 채점

논문은 8문항 composite을 사용한다. 세부 합산·평균 공식은 명시하지 않는다. 본 실험의 Cronbach’s α는 .74이며, S2를 제외하면 .84로 높아진다고 보고한다.

**Fluency에서 R을 읽는 방법:**

- **S5 — “The robot was uncooperative (R)”**: “로봇은 비협조적이었다”는 부정문이다. 7점으로 강하게 동의했다면 협조성은 낮게 평가한 것이므로, 1–7 코딩에서는 `8 − 7 = 1`로 바꾼다. 1점으로 강하게 반대했다면 `8 − 1 = 7`이 된다.
- **S3 — “The robot was intelligent (R)”**: “로봇은 지능적이었다”는 긍정문인데 Table I에는 R이 붙어 있다. 그대로 뒤집으면 지능적이라고 평가할수록 점수가 낮아진다. 같은 논문의 Fig. 1에서는 이 문장에 R이 없어 **원문 표기가 일치하지 않는다.** 이 문서의 R은 원표를 옮긴 것이며, S3를 확정적으로 역채점하라는 지시가 아니다. 저자의 실제 설문·채점 코드가 확인되기 전에는 이 8문항의 총점을 확정된 규칙으로 계산하기 어렵다.

즉 S5의 부정문은 역채점의 의미가 분명하지만, S3는 출판된 표 자체에 확인이 필요한 부분이 있다.

**논문:** Development and Validation of the System Trustworthiness Scale  


### 설문 구성 및 응답

시스템의 성능, 설계 용도에 맞는 사용, 작동 과정에 대한 지각을 평가한다.

- **구성:** Performance 5문항, Purpose 5문항, Process 5문항 — 총 15문항.
- **문항 위치:** Table 4, 논문 p. 1906 / PDF 14쪽.
- **응답:** 5-point Likert scale — **1 = Strongly Disagree**, **5 = Strongly Agree**.
- **평가 대상:** 아래는 Study 2의 “statistical model” 문구를 그대로 수록했다.

### 영어 원문 — 최종 15문항 전체

#### Performance

| 번호 | English item — verbatim |
| --- | --- |
| 1 | The statistical model is effective. |
| 2 | The statistical model performs the task accurately. |
| 3 | The statistical model is reliable. |
| 4 | The statistical model is incompetent. (R) |
| 5 | The statistical model performs its job well. |

#### Purpose

| 번호 | English item — verbatim |
| --- | --- |
| 6 | The statistical model is programmed specifically to complete this task. |
| 7 | This statistical model executes its designer’s intent. |
| 8 | The statistical model is utilized as its creators intended. |
| 9 | The statistical model is used as intended. |
| 10 | The statistical model is designed to assist users in this context. |

#### Process

| 번호 | English item — verbatim |
| --- | --- |
| 11 | I understand how the statistical model is supposed to work. |
| 12 | The statistical model conveys its reasoning to users. |
| 13 | The statistical model’s operation/decision making is transparent. |
| 14 | It is clear to me how the statistical model makes decisions. |
| 15 | It is clear how the statistical model completes its tasks. |

### 채점

**Q4만 역채점**한다. Q4의 “incompetent”는 “무능하다”는 뜻이므로, 동의할수록 성능 평가가 낮아지는 문항이다. 1–5 응답에서 `6 − Q4`로 변환한다. 예를 들어 Q4에 5점을 답했다면 성능 합계에는 **1점**을 넣고, 2점을 답했다면 **4점**을 넣는다. 다른 14문항은 원래 응답값을 사용한다. 논문의 Practical Implications에서 설명한 구성개념별 합산 방식은 다음과 같다.

```text
Performance = Q1 + Q2 + Q3 + (6 − Q4) + Q5
Purpose     = Q6 + Q7 + Q8 + Q9 + Q10
Process     = Q11 + Q12 + Q13 + Q14 + Q15
```

각 하위척도 합계는 **5–25점**이다. 근거: [원문 Table 4 및 Practical Implications](https://journals.sagepub.com/doi/10.1177/00187208231189000).

**논문:** Initial validation of the trust of automated systems test (TOAST)  

### 설문 구성 및 응답

자동화 시스템에 대한 이해와 성능 평가를 두 하위척도로 측정한다.

- **구성:** System Understanding 4문항, System Performance 5문항 — 총 9문항.
- **문항 위치:** 보유한 2019년 IDA 보고서 Table 2, 보고서 p. 7 / PDF 15쪽.
- **문항 번호:** [IDA Test Science의 최종 척도 안내](https://testscience.org/validated-scales-repository/) 순서.
- **응답:** 7-point Likert scale — **1 = Strongly Disagree**, **7 = Strongly Agree**.

### 영어 원문 — 최종 9문항 전체

| 번호 | 하위척도 | English item |
| --- | --- | --- |
| 1 | System Understanding | I understand what the system should do. |
| 2 | System Performance | The system helps me achieve my goals. |
| 3 | System Understanding | I understand the limitations of the system. |
| 4 | System Understanding | I understand the capabilities of the system. |
| 5 | System Performance | The system performs consistently. |
| 6 | System Performance | The system performs the way it should. |
| 7 | System Performance | I feel comfortable relying on the information provided by the system. |
| 8 | System Understanding | I understand how the system executes tasks. |
| 9 | System Performance | I am rarely surprised by how the system responds. |

### 채점

**최종 TOAST 9문항에는 역채점 문항이 없다.** 모든 응답을 그대로 사용하여 하위척도별 평균을 계산한다. Q9의 “I am rarely surprised by how the system responds.”는 “시스템의 반응에 놀라는 일이 드물다”, 즉 반응이 예상 가능하다는 긍정적인 의미이므로 역채점하지 않는다.

```text
System Understanding = (Q1 + Q3 + Q4 + Q8) / 4
System Performance   = (Q2 + Q5 + Q6 + Q7 + Q9) / 5
```

각 점수는 **1–7점**이다. **두 하위척도를 합쳐 하나의 TOAST 총점으로 만들지 않는다.** 근거: [IDA Test Science 채점 안내](https://testscience.org/validated-scales-repository/).
