## **📝 논문쓸 때 고려할  주요 사항**

1. 리뷰어의 입장에서 궁금한 내용, 나와야 하는 내용이 무엇일지 고려하고 글쓰기
2. 모든 제목 하단 목차에 내용 요약 2-3줄 정도 해주기
3. 주어+동사 가까이 위치, 문장은 간결하게
4. 3인칭 표현보다 1인칭 표현 지향(e.g., this study→ we)
5. 지칭대명사 사용 지양 (itself,  these, ..)→ 명확하게 밝혀서 써주기. 독자는 풀페이퍼를 읽지 않고 해당 파트만 읽을 수 있음
6. 초록은 본문과 별개 ! 따라서  Acronym 초록에 썼더라도 본문에서 다시한번 설명해줘야 함
7. 같은 개념에 대한 동일한 단어 사용하기

**📌 Writing revise 해줄때마다 반복되는 실수들**

- “When”은 대부분의 경우 “If”로 대체가능. Time critical한 내용일때만 when을 사용함
- 문장은 And, Or, But, So 으로 절대 시작하지 말것
- utilize, adopt 등은 대부분 use, employ로 대체 가능
- derive 대신 obtain
- get, take 와 같이 일반적으로 쓰일 수 있는 동사는 구체적인 동사로 사용하기. 예 : get -> obtain
- 대부분의 경우 “issue”는 더 구체적인 표현으로 대체 가능
- 영어에서 괄호로 써주는 것은 띄어쓰기를 해야함 Reinforcement Learning (RL) agent… 반면 한글에서는 띄지 않음
- 처음 나오는 Acronym은 한번은 다 풀어써줘야함 (예를 들어 냅다 처음부터 TAMP라고 적으면 그게 뭔지 모를 수 있음)
- Acronym은 어떤 용어를 다음에 또 쓸때 길게 쓰면 번거롭고 비효율적이기 때문에 줄여두고 그걸 쓰는건데 한번밖에 안나오면 굳이 줄일 필요없음. 예를들면 Task and motion planning (TAMP) 이렇게 해두고 TAMP를 두번다시 논문에서 안쓰면 굳이..?
- 이탤릭은 terminology임을 알려줄 수 있게 최초 한번 사용
- Firstly 썼으면, secondly, lastly 써야 함. First는 second, last로
- 명사 3단어 같이 오는 것도 너무 길다
- — 으로 문장 잇지 말고, 두 문장으로 나누거나 문장 다르게 표현하기
- 영어에서의 #은 number라는 뜻이고 10 아래의 숫자는 아라비아 숫자가 아닌 영어 스펠링으로 쓴다
- 단위, 시간(초,분) 과 같은건 전부 math로 작성한다.
- Figure는 흑백으로 프린팅했을 때 구분할 수 있도록 하는게 정석
- among, using, through 같은 것은 대문자로 쓰지말기
- 축약을 위한 아포스트로피(apostrophe, ' 또는 ' ) 사용 금지, 소유격 표현에서도 사용하지 않는게 정석.
- This method보다는 Our method, proposed method, the present method. This method는 남의 연구 같음
- Pseudo code 관련
    - \*itelic*은 변수를 의미, 상수의 경우 \text로 작성.
    - 인풋 아웃풋 PseudoCode와 매칭 확실히
    - 조건문의 and는 *itelic*으로 작성하면 안됨
    - not의 경우 **bold**를 사용하거나 논리 기호를 사용
    - max iteration의 경우도 빼먹지 말고 인풋에 명시

**📌 Reference 관련**

- 모든 cited 논문들은 양식에 일관성이 있어야 함. IEEE의 경우 다음의 양식을 지켜주세요 (첨부 이미지 참고)
- 학회논문은 학회논문집(Proceedings)에 실리게 됩니다. 따라서 in Proceedings of (학회명) 으로 되어야함. 그냥 학회명 바로 나오면 안됨.
- 학회, 저널 acronym(ICRA, IROS 등)을 병기할거면 그게 있는거는 다 써주기. 어떤것만 쓰고 어떤것은 안쓰지 않기.
- 학회논문은 구글에서 가져오면 2024 IEEE International … , 2024. 처럼 학회명에도 연도가 들어가고 맨뒤에도 연도가 들어가기도 함. 연도는 맨 뒤에거만 남기고 학회명은 잡다한거 다 빼기 (예를 들면 2024 Eleventh IEEE International Conference … 이런식이면 그냥 IEEE Int……)

- **레퍼런스 정리에 유용한 방법(ieee reference 쓸 때, 꿀팁)**
    1. bibtex 긁어 모으기
    2. bibtex 파일이랑 아래 guide 올리면서 gpt한테 반영해서 수정 요청
    3. 대부분 잘해주지만, 문법 에러 (e.g., ~~," ,) 같은 건 확인 및 수정 필요
    4. 전치사 생략: Proc. on (학회명) 이나 Proc. in (학회명) 같은 건 '. on ' 또는 '. in ' 처럼 전치사 검색해서 Proc. (학회명)이 되도록

**📌 Figure 관련** 

- Fig., Sec. Alg. 등의 다음에는 띄어쓰기를 넣는다. Fig.1이라고 쓰면 Figure1으로 쓰는 것과 같은 의미다.
- Figure에 들어가는 모든 글자는 caption 크기보다 크거나 같아야함. 그보다 작으면 안됨
- Figure는 만들때 주면에 white space를 최소화하고 바짝 크롭해서 만들어야 함
- Figure는 그림파일보다 PDF (또는 EPS) 포맷으로 만들어야함. 벡터형식이기 때문에 확대해도 깨지지 않음. 스크린샷 등이라서 불가피하게 그림 파일이어야할때는 JPG보다는 PNG가 좋음
