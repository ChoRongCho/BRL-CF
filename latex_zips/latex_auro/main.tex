\abstract{We present a method for deciding when a robot should seek external information and what it should ask during task execution. A robot operating with incomplete information can fail to determine the current state of the world, leading to task failure. However, resolving every such ambiguity through external queries would incur unnecessary information-acquisition costs. The key challenge is therefore to determine both when a query is necessary and what information should be requested. 

To address this problem, we maintain a weighted belief over alternative symbolic world states throughout task execution. After each action and observation, the framework computes an entropy-based confidence measure and determines whether the belief is sufficiently resolved according to a predefined threshold. If additional information is required, the framework selects the symbolic fact expected to reduce uncertainty the most and queries an external expert to refine the belief. We evaluate the framework in two robotic task domains with different uncertainty structures and compare it with alternative query-timing and query-selection strategies. The results show that query timing primarily affects task success, while query selection affects the number of required queries. Compared with conformal-prediction-based and reward-based strategies, our method achieves higher task success without substantially increasing the number of queries.}

\keywords{Planning under uncertainty, uncertainty-aware querying, knowledge-based planning, autonomous robots}
