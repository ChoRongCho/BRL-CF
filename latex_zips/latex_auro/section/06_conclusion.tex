\section{Conclusion and Future Work}
We present a method that uses state uncertainty to determine query timing and query selection during robot task execution. Belief confidence determines whether to request external information, and expected entropy reduction determines which state fact to verify. The responses update the belief used for subsequent planning. Experiments in WasteSorting and TomatoHarvesting show that confidence-based timing supports high task success, while entropy gain reduces query count at similar success rates. Physical robot experiments also show that additional queries do not consistently increase total execution time.

Future work includes richer feedback beyond binary state verification and more scalable belief construction for larger task domains. We also aim to incorporate response reliability and the information available to feedback sources into query selection.
