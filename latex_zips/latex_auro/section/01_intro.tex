\cp{Robots often encounter uncertainty during task planning and execution due to perception errors~\citep{kaipa2016addressing} and execution failures~\citep{kaelbling1998planning}. For example, a robot may be uncertain whether a tomato is ripe or whether a pick or place action succeeded. The robot can ask an external agent to provide missing information or select the next action. By initiating queries, the robot reduces the need for continuous monitoring by the external agent. However, querying involves a trade-off between task success and the number of queries. Too few queries can leave uncertainty unresolved and lead to task failure. Frequent queries increase interaction costs, such as response latency, token use for a vision-language model (VLM), and human workload. A further challenge is that simply increasing the number of queries does not necessarily improve task success. The robot may still fail if queries come too late or do not resolve the uncertainty. The robot must therefore determine \textit{when} to request feedback and \textit{what} to ask to improve task success while limiting the number of queries required.}




% Recent uncertainty-aware systems selectively request external feedback during task execution. Existing approaches commonly trigger queries based on prediction confidence, including conformal prediction~\citep{ren2023robots, liang2024introspective, mullen2025lbap}, or on the expected effect of a query on task reward~\citep{burks2021collaborative, anand2025adaptive}. \cp{However, a confident action prediction does not ensure that the underlying state estimate is correct. Under reward-based criteria, the robot may also execute an action without querying even when state uncertainty remains. Both approaches can therefore miss opportunities to verify the state information needed for successful execution, leading to task failure. We use state uncertainty to determine when verification is needed and expected uncertainty reduction to select what to ask.}

Existing methods often use confidence in predicted actions or expected task return to decide when and what to query. Methods based on conformal prediction request external feedback to clarify the choice among candidate actions or plans if multiple candidates remain in the prediction set~\citep{ren2023robots,liang2024introspective}. However, a single candidate does not ensure a correct estimate of the current state. The robot may therefore proceed without querying despite an incorrect state estimate. The prediction set may also exclude the correct action or plan. Approaches based on a partially observable Markov decision process (POMDP) model queries as planning actions~\citep{burks2021collaborative,burks2023harps}. The planner uses expected cumulative reward to decide whether to query and which query to select. However, neither approach explicitly determines when to query and what to ask to reach a required level of confidence in the current state. The robot may therefore execute an action before obtaining the necessary state information or require additional queries to reach sufficient confidence.

In this paper, we present a method that uses uncertainty about the current symbolic state to determine when to request feedback and what to ask. We formulate task planning as a POMDP~\citep{kaelbling1998planning} and use symbolic facts and action models~\citep{davis1993knowledge,fikes1971strips} to construct a weighted belief over reachable states. To determine when to query, the robot computes belief confidence from normalized entropy, which decreases as probability concentrates on a single state. The robot requests external feedback if belief confidence falls below a threshold. To determine what to query, the robot selects the state fact with the greatest expected reduction in belief entropy to reduce the number of queries needed to reach the confidence threshold. Each response provides evidence for updating the belief. Once confidence reaches the threshold, the robot updates the knowledge base with the maximum a posteriori state estimate and resumes planning and execution.

We evaluate our method on two robotic tasks in partially observable environments with sensing errors. \cp{In simulation with correct oracle responses}, we compare our method with strategies based on conformal prediction and expected task reward. We then conduct physical robot experiments using a VLM and human participants as external responders to compare our method with a baseline based on conformal prediction. Our method achieves higher task success rates than all evaluated baselines in simulation and than the selected baseline on physical robots with both VLM and human feedback. Ablation experiments indicate that the query timing criterion primarily affects task success. With our query timing criterion fixed, our query selection criterion reduces the number of queries required. We also vary the confidence threshold to examine the trade-off between task success and query count. Finally, interviews with all five participants provide qualitative insights into their experiences with both methods. Experiments demonstrate that our method achieves the highest task success among the evaluated approaches while using queries efficiently.

Our contributions are as follows:
\begin{itemize}
\item We determine when to query from belief uncertainty to improve task success.
\item We select what to query by expected entropy reduction, reducing query counts under a fixed timing criterion.
\item We demonstrate higher task success than the evaluated baselines in simulation and on physical robots with VLM and human feedback.
