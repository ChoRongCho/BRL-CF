\section{Introduction}~\label{intro}
Robots operating in real-world environments often have incomplete or unreliable information about the current task state due to perception errors~\citep{kaipa2016addressing}, execution failures~\citep{kaelbling1998planning}, and unexpected environmental changes~\citep{kurniawati2016online}. If such uncertainty is not resolved, the robot may make incorrect decisions and fail the task. \cp{The robot can proactively request information from an external feedback source to reduce this uncertainty~\citep{dragan2013legibility, goodrich2008human}. However, frequent queries can incur substantial costs in time and workload~\citep{chen2014human}.} The robot must therefore determine \textit{when} external information is necessary and \textit{what} information should be requested.

Recent uncertainty-aware systems selectively request external feedback during task execution. Existing approaches commonly trigger queries based on prediction confidence, including conformal prediction~\citep{ren2023robots, liang2024introspective, mullen2025lbap}, or on the expected effect of a query on task reward~\citep{burks2021collaborative, anand2025adaptive}. \cp{However, a confident action prediction does not ensure that the underlying state estimate is correct. Under reward-based criteria, the robot may also execute an action without querying even when state uncertainty remains. Both approaches can therefore miss opportunities to verify the state information needed for successful execution, leading to task failure. We use state uncertainty to determine when verification is needed and expected uncertainty reduction to select what to ask.}
Existing methods use action prediction confidence or expected task reward to guide querying decisions. For example, KnowNo uses conformal prediction sets to determine when to request an action choice~\citep{ren2023robots}, while IntroPlan combines conformal prediction with retrieved reasoning examples for candidate evaluation~\citep{liang2024introspective}. Both methods may proceed without verification if incorrect perception produces a confident action prediction, and action-selection responses may overlook execution preconditions. Instead, POMDP-based approaches evaluate queries through their expected contribution to task reward~\citep{burks2021collaborative}. Our POMCP-Q baseline searches over Boolean state queries and physical actions together. The expanded action space and delayed benefits of verification can make useful queries difficult to identify under a finite search budget, leaving information needed for successful execution unresolved.

Existing approaches commonly trigger queries based on prediction confidence, including conformal prediction~\cite{ren2023robots, liang2024introspective, mullen2025lbap}, or on the expected effect of a query on task reward~\cite{burks2021collaborative, anand2025adaptive}. While these strategies reduce unnecessary interaction, they do not explicitly use uncertainty about the current task state. As a result, they may fail to identify when additional state information is needed or what information would be most useful to request. In contrast, we determine when to query based on state uncertainty and what to query based on its expected reduction.


In this paper, we present a method that \cp{maintains and updates} a weighted belief over possible task states throughout execution. We formulate decision making as a partially observable Markov decision process (POMDP)~\citep{kaelbling1998planning} and represent task knowledge using a STRIPS-style symbolic model~\citep{davis1993knowledge,fikes1971strips}. The belief is updated after each action and observation, and its uncertainty is used to determine when external information is needed. If a query is triggered, the robot selects the state fact expected to reduce uncertainty the most and asks an external expert to verify it. The response is incorporated into the belief, which is then used for subsequent planning and execution.




We evaluate the method in tomato harvesting and waste sorting, which exhibit different forms of state uncertainty. \cp{In simulation with correct responses}, we analyze the effects of query timing and query selection and compare against conformal-prediction-based and reward-based strategies. We then evaluate \cp{feedback from a vision-language model (VLM) and human participants in physical robot experiments} and compare against KnowNo~\citep{ren2023robots}. Finally, interviews with five participants provide qualitative observations on the proposed querying behavior. \cp{The experimental results show that our method achieves higher task success than the baselines in simulation and with VLM and human feedback on physical robots. Ablation results indicate that query timing primarily affects task success, whereas query selection reduces the number of queries required.}

Using \cp{oracle feedback}, we analyze the effects of query timing and query selection and compare against conformal-prediction-based and reward-based strategies. We then evaluate non-oracle feedback from a VLM and human participants and compare against KnowNo~\cite{ren2023robots}. The main contributions of this work are as follows:

\begin{itemize}

\item We determine when to query based on uncertainty in the current task state and show that query timing has a substantial effect on task success.

\item We prioritize state information that is expected to reduce uncertainty and show that query selection affects the number of required queries.

\item We evaluate the proposed method in simulation and on physical robots with VLM and human feedback, demonstrating higher task success than the evaluated baselines.

\end{itemize}
